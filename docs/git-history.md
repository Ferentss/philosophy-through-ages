# Історія Git українською мовою

В архіві збережено **9 справжніх локальних комітів**. Повідомлення усіх комітів написані українською. Їх видно у вкладці **Source Control** Visual Studio Code та через команду:

```powershell
git log --oneline -9
```

Коміти охоплюють такі етапи розробки:

1. Початок: збережено вихідну структуру повностекового проєкту.
2. Залежності: узгоджено версії Payload CMS та адаптера Blob.
3. Дані: збережено налаштування CMS та описано безпечні міграції PostgreSQL.
4. API: захищено маршрути сторінки та зберігання медіафайлів.
5. Фронтенд: додано перевірку JSON та вдосконалено мобільне меню.
6. Тести: перевірено відповіді API, приватність та типи блоків.
7. Документація: оновлено запуск у VS Code, перевірки та історію Git.
8. Запуск: виправлено встановлення CMS та перевірку залежностей.
9. TypeScript: додано спільні команди перевірки, тести й пояснення типізації.

**Зверніть увагу:** повідомлення перших восьми комітів були переведені українською через переписування локальної історії Git, тому їхні SHA змінилися. Якщо стару історію вже публікували на GitHub, не переписуйте віддалену гілку без узгодження з іншими учасниками. Додавати GitHub remote тут не потрібно: GitHub не підключено.

Коміти створені з технічним ім'ям автора `Local Project Revision`, а не від імені вашого GitHub. Щоб завантажити в **новий** репозиторій:

```powershell
git remote add origin https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ.git
git branch -M main
git push -u origin main
```

Перевірте `.gitignore` перед публікацією: справжні `.env`, секретні ключі, `node_modules` і результати збірки не мають потрапляти в репозиторій.
