# Історія Git у ZIP

Для навчального завдання створено 7 справжніх **локальних** комітів в одному Git-репозиторії. Їх можна побачити у вкладці Source Control у VS Code або командою `git log --oneline -7`.

Коміти розділено за змістом: базовий стан, залежності, дані/міграції, API/безпека, фронтенд/TypeScript, тести, документація.

Коміти виконано технічним підписом `Local Project Revision`, який не є вашим особистим обліковим записом. Нічого не завантажено у ваш GitHub: якщо потрібно здати посилання на репозиторій, створіть порожній репозиторій у своєму акаунті й виконайте у VS Code:

```powershell
git remote add origin https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ.git
git branch -M main
git push -u origin main
```

Підставляйте **свої** значення замість шаблонів. Перед відправленням переконайтесь, що `.env` і токени не потрапили до Git.

Додатковий коміт усуває проблему запуску npm: CMS тепер відновлює lock-файл через npm install, а `dev` перевіряє встановлення залежностей. Для завершення перевірки CMS потрібен npm-реєстр.
