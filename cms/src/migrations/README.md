# Міграції PostgreSQL

`20261020_074222.ts` — схема з базового проєкту. `20261026_philosophy.ts` — адаптація колекцій і блоків до теми філософії.

**Увага:** другу міграцію створено вручну в попередній версії проєкту. Її не було протестовано з реальною PostgreSQL через відсутність підключення. Також для неї немає згенерованого Drizzle snapshot JSON, тому команда `migrate:create` може вимагати синхронізації snapshot перед наступними змінами.

Для нової *окремої тестової* бази після `npm ci` та налаштування `DATABASE_URL` виконайте в `cms/`:

```powershell
npm run migrate:status
npm run migrate
npm run generate:types
```

За результатами реальної перевірки звірте схему з Payload і створіть нову коректну міграцію офіційною командою `npm run migrate:create` перед розгортанням. **Не застосовуйте неперевірену ручну міграцію до production бази з важливими даними.** Застосування й успіх не засвідчено.
